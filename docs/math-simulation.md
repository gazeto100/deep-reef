# Deep Reef: simulation results

Generated by `npm run math:sim -- --rounds 10000000 --seeds 20240601,777 --doc`
(total bet 20 credits; every figure is a multiple of total bet). The simulator plays
complete rounds through `SlotEngine.playRound`, the same code the server uses, and
compares them with the exact calculator ([math-report.md](math-report.md)).
